# План перехода на единый портал mashuk.online

Единый ресурс для АНО «Центр знаний «Машук»: витрина программ, лендинги,
формы заявок и платформа сопровождения — на одном архитектурном стеке,
с единой админкой. Уход с Tilda и от iframe-костылей.

## 1. Зафиксированные решения

- **Стек:** Next.js 16 (App Router) + React 19 + TypeScript + Tailwind 4 + Drizzle ORM + PostgreSQL.
- **Основа:** код PlatformMashuk (хаб, опросы, чаты, админка программ, деплой).
- **Границы:** только `mashuk.online`. Сайт `центрзнаниймашук.рф` и `bestpractice`
  остаются как есть, линкуются.
- **LMS:** внешний `lms.mashuk.online`, витрина ссылается на него (не заменяем).
- **Данные:** существующие заявки переносятся в новую БД.
- **Деплой:** VPS Timeweb (Docker Compose + Caddy TLS), домен `mashuk.online` переводится туда.
- **Заявки привязываются к программам** через `program_id`.

## 2. Целевая архитектура

- Один репозиторий `MashukOnline`, один Postgres, один деплой, одна админка.
- К схемам платформы (`programs`, `members`, hub, polls, chats) добавляются
  таблицы форм, переписанные на Drizzle:
  - `seminar_applications`
  - `participant_details`
  - `municipal_applications`
  Каждая — с `program_id` (FK на `programs.id`), `deleted_at`, `payload_raw jsonb`.
- Файлы (согласия, портфолио, сканы паспортов) — через существующий blob-store/S3,
  приватно, доступ только администратору.
- Авторизация одна: сессии платформы (`members` + cookie) и `requireAdminArea()`.
  Отдельный HMAC-cookie форм не используется.
- Роутинг:

```
mashuk.online
  /                              главная (ручной код)
  /programs, /programs/[slug]    каталог и страница программы
  /programs/[slug]/hub, /cabinet сопровождение
  /apply, /info, /muni           формы заявок
  /events/seminar, /events/media, /results/education-height   лендинги
  /admin                         единая админка
```

## 3. Фазы работ

### Спринт 1 — каркас и основа
Репозиторий `MashukOnline`, перенос кода PlatformMashuk, бренд-ассеты,
`ПЛАН.md`, локальный запуск `npm run dev`.

### Спринт 2 — формы (порт в Next.js)
- Drizzle-схема заявок с `program_id`.
- `/apply` — 48 полей, portfolio.pdf + согласие.
- `/info` — ~50 колонок, скан паспорта (проверка сигнатур PDF/JPG/PNG, 20 МБ).
- `/muni` — СНИЛС/ИНН/регион, PDF-согласия.
- «Потоки» семинара мапятся на программы платформы.
- PDF-согласия: порт на `pdf-lib` (эталон координат — `municipal_consent.py`),
  fallback — Python-микросервис только под overlay.
- FastAPI продолжает работать до переезда (параллельный прогон).

### Спринт 3 — единая админка
- `/admin`: Программы (есть) + Заявки (табы Семинар / Данные / Муниципалитеты),
  Опросы, Материалы, Состав.
- Из `admin_api.py`: фильтры, сортировка, пагинация, корзина (soft-delete),
  Excel (`exceljs`), ZIP согласий, подписанные ссылки (HMAC через `crypto`).

### Спринт 4 — витрина и лендинги
- Главная из `index.html` + `tilda-*-block.html` → React-компоненты/Tailwind.
- `seminar-landing`, `media-landing`, `education-height-results` → страницы,
  без iframe. Карточки курсов ссылаются на `lms.mashuk.online`.

### Спринт 5 — миграция данных
- Экспорт трёх таблиц текущей БД + `uploads/` → новая схема и хранилище,
  маппинг на `program_id`, сверка записей и ссылок на файлы.
- Команда переноса (`scripts/migrate-legacy.ts`):

```bash
LEGACY_DATABASE_URL=postgres://…старая… \
DATABASE_URL=postgres://…новая… \
pnpm migrate:legacy --uploads=/path/to/old/uploads [--program=<slug>] [--dry-run]
```

  Заявки без `_legacy_id` переносятся, файлы копируются в хранилище под ключом
  `applications/<имя>`; повторный запуск пропускает уже перенесённые.

### Спринт 6 — переезд домена
- Приёмка на поддомене → DNS `mashuk.online` на VPS → 301 с Tilda →
  бэкапы (`deploy/backup.sh`) и мониторинг → вывод Tilda.

## 4. Риски

- **PDF overlay в Node** — главный риск; при расхождении координат
  оставляем Python-микросервис только под PDF.
- **Паритет Excel/ZIP** после смены библиотек.
- **PII** (сканы паспортов) — только приватное хранилище и админ-доступ.
- **Next.js 16** — «не тот Next» (см. `AGENTS.md`): сверяться с локальными доками
  `node_modules/next/dist/docs/`.
