# MashukOnline — единый портал «Центр знаний «Машук»

Единый ресурс АНО «Центр знаний «Машук» на `mashuk.online`: витрина программ,
лендинги, формы заявок и платформа сопровождения слушателей — на одном стеке
и с единой админкой. Приходит на смену Tilda и iframe-формам.

План перехода и фазы работ — в [ПЛАН.md](ПЛАН.md).
Деплой — в [ДЕПЛОЙ.md](ДЕПЛОЙ.md), локальный запуск — в [ЗАПУСК.md](ЗАПУСК.md).

## Что входит

- **Витрина программ** и страница программы (описание, расписание, материалы).
- **Лендинги** семинаров и итогов — ручной код, без Tilda и iframe.
- **Формы заявок**: семинар (`/apply`), данные участников (`/info`),
  муниципалитеты (`/muni`) — с загрузкой файлов и PDF-согласиями.
- **Платформа сопровождения**: рабочее пространство программы (канал, чаты,
  материалы, участники), живые опросы и квизы, личный кабинет.
- **Единая админка** `/admin`: программы, заявки (три формы), опросы,
  материалы, состав. Выгрузка Excel и ZIP согласий.
- **Вход без регистраций**: по паролю программы и личному паролю.

## Технически (кратко)

- **Next.js 16** (App Router) + **React 19**, **TypeScript**, **Tailwind 4**.
- **PostgreSQL** через **Drizzle ORM**; без базы работает демонстрационный режим.
- **Реалтайм** — Server-Sent Events; редактор текста — **TipTap**.
- **Файлы** — локальное хранилище или S3-совместимое.
- **Ошибки** — Sentry-совместимый приём (GlitchTip).
- **Деплой** — Docker Compose (приложение + PostgreSQL + Caddy с HTTPS).
  Образы собираются в GitHub Actions и публикуются в `ghcr.io`; резервные
  копии — по cron.

## Структура

```
src/            приложение Next.js (app, components, lib)
drizzle/        схема и миграции базы
public/brand    брендинг для рантайма (логотипы, иконки, маскот, шрифты)
assets/brand-src исходники брендинга (AI/PNG/SVG, шрифты)
docs/brand      бренд-гайдлайн
deploy/         Caddy, Postgres, бэкапы, CI-конфиги
scripts/        сидинг, админ, скриншоты
```

## Запуск

```bash
npm install
npm run dev     # http://localhost:4321
```

Для запуска база не нужна — витрина работает на демонстрационных данных.
