РЕКОМЕНДУЕМЫЕ ОБЪЁМЫ
--------------------
Тест (как сейчас):              1 vCPU, 1 ГБ RAM + swap 2 ГБ, 20 ГБ диска
Прод (рекомендуется):           2 vCPU, 2–4 ГБ RAM, 40–50 ГБ диска
Прод + мониторинг (Grafana):    2–4 vCPU, 4 ГБ RAM, 50 ГБ диска

Что занимает место:
  База данных (604 заявки):     ~14 МБ
  Тома приложения:              ~89 МБ
  Файлы заявок (854 шт.):       ~0.5–3 ГБ
  Образы и кэш Docker:          до 2–3 ГБ (чистятся)

Итого 40–50 ГБ диска закрывают базу, файлы, образы и бэкапы с запасом.

РАЗВЁРТЫВАНИЕ С НУЛЯ
--------------------
1. Подготовка сервера (Ubuntu): Docker, Compose, swap 2 ГБ.
   Готовый cloud-init: deploy/cloud-init.yaml

2. Код и конфигурация:
   sudo mkdir -p /opt/mashuk && sudo chown "$USER" /opt/mashuk
   git clone https://github.com/ZuevPU/MashukOnline.git /opt/mashuk
   cd /opt/mashuk
   cp deploy/.env.production.example .env
   nano .env

3. Запуск (образ тянется из ghcr.io, на сервере не собирается):
   docker compose --env-file .env pull app
   docker compose --env-file .env up -d

4. Миграции и администратор:
   docker compose --env-file .env --profile tools run --rm tools pnpm db:migrate
   docker compose --env-file .env --profile tools run --rm tools pnpm admin:create -- admin@czmashuk.ru "Администратор"

5. Проверка:
   curl -s https://DOMAIN/api/health

DNS: A-запись домена -> IP сервера. TLS Caddy получит автоматически.


ОБСЛУЖИВАНИЕ
------------
Бэкап (база + файлы) ежедневно, cron:
  30 3 * * * cd /opt/mashuk && ./deploy/backup.sh >> /var/log/mashuk-backup.log 2>&1

Автообновление из ghcr.io каждые 5 минут, cron:
  */5 * * * * bash /opt/mashuk/deploy/autoupdate.sh >> /var/log/mashuk-autoupdate.log 2>&1

Очистка места при нехватке диска:
  docker builder prune -af && docker image prune -af


КОГДА УВЕЛИЧИВАТЬ СЕРВЕР
-----------------------
- Диск > 80% или много файлов заявок -> 40–50 ГБ или S3.
- Swap активно используется -> 2–4 ГБ RAM.
- Много одновременных пользователей в хабе/опросах -> 2–4 vCPU и отдельная БД.
- Мониторинг (Prometheus/Grafana) включается профилем metrics, +1–2 ГБ RAM.
